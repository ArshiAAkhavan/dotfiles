# Dotfiles
Not too fancy and eye-catching, but sure is hella-ergonomic!
![./screenshot.png]

## Prerequisites 
Don't know! just run them until you see a `command <DEPENDANCY> not found` and then install the depancies on your system!

## Setup
You can either: 
1. run `setup.sh` which basically links the config files to where they should be. 
```bash 
./setup.sh
```
2. or you can hand-pick the applications/configurations you require. But be aware that some applications may have dependancies to eachother.
